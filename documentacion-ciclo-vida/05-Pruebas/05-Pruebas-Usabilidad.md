# 5. Pruebas de usabilidad

| Aspecto evaluado | Criterio | Resultado |
|---|---|---|
| Mensajes de error | Dicen que paso y que hacer, no solo "error" | Cumple (ej. mensaje de inventario insuficiente detalla el producto y la cantidad disponible) |
| Formularios largos | Ciudad y pais como desplegable, no texto libre | Cumple, reduce errores de digitacion |
| Clave segura | Medidor visual en vivo + boton de sugerencia | Cumple |
| Navegacion por rol | Cada rol ve solo los accesos que le sirven | Cumple |
| Selector de idioma | Un clic, sin perder la sesion | Cumple |
| Selector de vendedor en checkout | Opcional, no bloquea la compra si no se elige | Cumple |
| Venta asistida | El vendedor no necesita la clave del cliente | Cumple |
